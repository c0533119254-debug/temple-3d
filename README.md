# הדמיית בית המקדש השלישי

הדמיה תלת־ממדית של בית המקדש השלישי לפי יחזקאל והמלבי״ם (ועם מצב "לפי הרמב״ם"), בתוך ירושלים של היום.

**הענף `main` הוא מקור האמת.** כל עבודה מתחילה ממנו ונכנסת אליו.

## איך פותחים

הקבצים נטענים זה מזה, לכן צריך לפתוח דרך שרת (לחיצה כפולה על הקובץ לא תעבוד):

```
python3 -m http.server 8000
```

ואז לפתוח בדפדפן: http://localhost:8000
מצב בדיקה: http://localhost:8000/#review=1

גם Netlify מגיש את התיקייה כמו שהיא (ראו `netlify.toml`).

### חשוב לדעת על הקבצים ב־`src/`

כל הקבצים ב־`src/` הם **חלקים של פונקציה אחת גדולה**. הם משתמשים זה במשתנים של זה,
ולכן אף קובץ לא רץ לבד. `loader.js` מחבר אותם לפי `parts.txt` ומריץ אותם כסקריפט אחד.
הקובץ הראשון פותח את הפונקציה והאחרון סוגר אותה.

## כללי העבודה (Claude וגרוק)

1. מקור אמת אחד: הענף `main`. לא עובדים יותר מה־artifact.
2. לפני כל עבודה מושכים את הגרסה האחרונה מ־`main`.
3. עובדים במקביל (עדכון של שמואל, 5.11.2026): Claude ב־`src/temple` וב־`src/core`, גרוק ב־`src/city`. כל אחד בענף משלו.
4. כל שינוי נשמר כ־commit קטן, עם הסבר קצר בעברית: מה השתנה ולמה.
5. בסוף כל עבודה כותבים לשמואל בשורה אחת מה נעשה ומה נשאר.
6. לא מוחקים ולא משכתבים קוד של השני בלי לשאול את שמואל קודם.
7. דיוק הלכתי לפני ביצועים. כל מספר צריך מקור, ולא ממציאים נתונים.

ובנוסף:

- גרוק בודק וממזג ל־`main` ענף אחד בכל פעם, אחרי שבדק שהאתר עובד.
- שינוי בקבצים משותפים (`index.html`, `css/`, `src/parts.txt`, `src/loader.js`) או בקבצי עיר שהמקדש תלוי בהם – רק דרך `REQUESTS.md`.
- בכל דבר במודל מסמנים: 📜 מפורש / ⚖️ הלכה / 💡 הצעה.
- לא שוברים דברים שכבר עובדים. לפני שמבקשים מיזוג: פותחים את ההדמיה, בודקים שאין שגיאה
  ליד מספר הגרסה (בפינה השמאלית העליונה), ומצרפים תמונת לפני ואחרי.
- מספר הגרסה נמצא ב־`index.html` (`גרסה 91`). גרוק מעלה אותו באחד בכל מיזוג (כדי ששני ענפים לא ישנו אותו במקביל).

## לפרסם לקישור של ה־artifact (אם צריך)

```
python3 tools/build.py
```

נוצר `dist/temple-3d.html` – קובץ אחד, זהה לגמרי למה שרץ מהתיקיות. מפרסמים אותו יחד עם התמונות.
